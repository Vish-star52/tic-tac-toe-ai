# Tic-Tac-Toe AI

A desktop tic-tac-toe game built with Python and Pygame. Play against an AI opponent that uses the minimax algorithm.

## Requirements
- Python 3.9+
- Pygame
- NumPy

## Run locally

```bash
python -m pip install -r requirements.txt
python aiTictac.py
```

## Controls
- Click an empty square to make a move.
- Click **REFRESH** to start a new game.
- Close the window to quit.
